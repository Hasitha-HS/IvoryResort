# Ivory Resort — Next.js starter

Lightweight Next.js 16 + TypeScript + Tailwind starter for the Ivory Resort site.

Getting started:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm start
```

Notes:
- The `/app/api/email/route.ts` endpoint is a stub — connect SendGrid/SES in production.
- Comments and simple auth are client-side using `localStorage` for now.
